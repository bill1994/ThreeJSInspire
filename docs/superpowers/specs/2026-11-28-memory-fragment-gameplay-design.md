# 记忆碎片：玩法设计

状态：草稿。2026-11-28 边定边记，当晚补成一整份；2026-11-29 定了一局的时长和滑杆。故事部分见 [故事大纲](2026-11-28-memory-fragment-story-outline.md)。「碎片的细节」往后是写给实现的人看的，其中标了"我补的"都可以改。

## 已定

1. **一局玩完。** 从黄昏飞到正午，一局大约十五到二十分钟。中途退出要记住已经捡到的东西，下次接着玩。这一条是你定的，2026-11-28。时长在 2026-11-29 改成八分钟左右，见第 9 条。
2. **来自故事大纲的要求。** 十五件日常物件，分三幕，每幕五件。同一件东西会再出现，并且变旧。天色跟着幕走。被坏情绪碰到时东西跑远，没有失败。
3. **一次只亮一件，亮在飞机前方。** 捡到一件，下一件才在飞机前方出现。这一条是你定的，2026-11-28。
4. **东西跟着玩家生成，不摆在固定地点。** 世界本来就是无限往前生成的，所以下一件永远在飞机前方生成。这一条是你定的，2026-11-28。
5. **要有位置提示。** 玩家飞偏了也找得回正在追的那一件。这一条是你定的，2026-11-28。
6. **被坏情绪碰到时的反馈。** 正在追的那一件被推远，镜头摇晃。这一条是你定的，2026-11-28。你说的"等"里还有哪些反馈，我先猜了几条，见下面「碰到以后的其它反馈」，等你核对。
7. **坏情绪是一群小黑片。** 像风卷起来的碎纸，转着圈追过来，碰到就散开。给你看过三版示意图（影雾、狼影、纸鸟群），你选了这一版，2026-11-28。
8. **捡到一件东西时，出一张纪念卡。** 画面暗一拍，一张小卡片从下面升上来，左边是那样东西，右边是那段字，停一会儿再收回去。给你看过三版示意图（字幕式、留在屏上、纪念卡），你选了这一版，2026-11-28。
9. **一局八分钟左右。** 件与件之间隔远一点，换幕的时候加一段只管飞的过渡。故事不加字，飞行手感不动。这一条是你定的，2026-11-29。
10. **一局进行中，调节面板里的时间滑杆和天色预设藏起来。** 通关以后的自由飞行里恢复。这一条是你定的，2026-11-29。

## 位置和提示的细节

这四条是我先定的，可以改。

1. 下一件在飞机前方大约六百到九百米处出现，左右和高低各偏一点，所以每次飞法不一样。2026-11-29 从三百到五百改远，为的是把一局撑到八分钟左右。
2. 出现以后它停在那个位置，不跟着飞机走。
3. 如果飞离它超过大约一千五百米，它悄悄消失，重新在飞机前方出现。这样不会出现找不到的情况。
4. 提示分两种。东西在屏幕里的时候，它带一道竖直的光。东西跑出屏幕的时候，屏幕边缘出现一个箭头，指着它的方向，旁边写着还有多少米。

## 坏情绪的细节

示意图里演过的，加上下面这些我补的数，都可以改。

1. 一群二十来片，抱成一团飞，每一片自己在群里翻。
2. 从画面边上冒出来，朝飞机追。追的速度比飞机平时快一点，用力加速或者转弯能甩开。
3. 离飞机十米以内算碰到。
4. 碰到以后这一群当场散开，几秒内不再来。下一回从别的方向冒出来。
5. 第一幕来得少，第二幕最勤，第三幕几乎没有。
6. 颜色：黄昏是深灰紫，夜里接近黑，带一圈淡蓝的边。不加这道边，夜里看不见。
7. 靠近的时候有纸片哗啦的声音，从哪边来声音就偏向哪边。
8. 多久来一回：第一幕捡完第一件以后开始，大约每三十秒一回。第二幕大约每二十秒一回。第三幕只在开头来一回。

## 碰到以后的其它反馈

这几条是我先猜的，示意图里画出来了，等你核对。

1. 画面暗一拍，再回过来。
2. 正在追的那一件被一团暗影裹着卷向远处，越缩越小。过几秒它在新的位置重新亮起来，落点见第 4 条。
3. 一声闷响。
4. 卷远是卷到飞机前方大约一千二百米处，比原来远一截，方向偏一点，得再追一阵。要在"飞离一千五百米就重新出现"那条线以内，不然一被卷走它就换地方了。

## 碎片的细节

这几条是我补的，可以改。

1. 一幕里五件的先后是打乱的。开一局的时候抽一个编号，这个编号决定这一局每幕里五件的顺序。中途退出再进来，顺序不变。
2. 下一件的高度跟着飞机走，夹在二十五米到两百米之间。下面有岛的话，比岛顶高出四十米以上。
3. 飞机中心离它十二米以内，算捡到。
4. 捡到的那一下，它飞向飞机，化成一个光点，然后卡片出来。
5. 东西的模型：碗、手电筒、信封、手机、照片，五样用简单的几何体拼。每幕一个样子：第一幕是新的，第二幕是旧的，第三幕是现在的样子。先求认得出来，不求细。
6. 那道光是暖色的，夜里亮一些。
7. 屏幕边缘的箭头贴着 9:16 画框的边，离边一点距离。旁边的米数取整到十。东西在屏幕里的时候不写米数。

## 纪念卡的细节

这几条是我补的，可以改。示意图里卡片只停了三秒，那是为了让三版好比较，读不完。以这里为准。

1. 捡到的瞬间画面暗一拍，半秒左右回亮。飞行照常，不停。
2. 卡片从屏幕下面升上来，停在下方。左边是那样东西的小图，右边是那段字。
3. 停多久看字数，以读得完为准：按每秒读六个字算，再加两秒。五十个字上下的大约十秒。
4. 不想等，点一下屏幕就收走。手指没怎么移动才算点，和拖动转向不冲突。
5. 卡片还在的时候又捡到一件，直接换成新的一张。
6. 被坏情绪碰到，不影响卡片。
7. 卡片角上一行小字：第几幕，第几件。
8. 开场的引子和结尾也用这种卡片。引子三句是三张，一句一张。结尾一段分成三四张。都是一张读完出下一张，点一下可以直接出下一张。

## 一局怎么走

1. 进入游戏，飞机照常起飞。进度是零的，放引子：三张卡片。
2. 第一幕，黄昏。追五件东西，每捡到一件出一张纪念卡。
3. 第一幕捡完，出一张只写幕名的卡片，然后是一段只管飞的过渡，大约一分钟。过渡里天色从黄昏走到入夜，不出东西。过渡完了进第二幕，第二幕里边捡边往深夜走。
4. 第二幕捡完，一样：幕名卡，一段过渡。过渡里天色从深夜走到清晨。过渡完了进第三幕，第三幕里边捡边走到正午。
5. 第三幕的第五件捡完，卡片收走以后放结尾。
6. 结尾放完，这一局就完了。天色停在正午，可以接着自由飞，不再出东西。再开一局要重新打开页面。

**一局八分钟左右，是这么凑的。** 下一件在前方六百到九百米，巡航每秒四十六米，直飞十三到二十秒，加上转身找它，一件大约二十秒，十五件五分钟。两段过渡两分钟。引子和结尾一分钟。加起来八分钟上下。读卡片和飞是同时的，不另占时间。

## 换幕的过渡

过渡是我加的，可以改。

1. 每幕开头先出一张卡片，上面只有幕名，比如"第二幕 长大"，三秒收走。第一幕的那张接在引子后面。
2. 第二幕、第三幕开头各有一段过渡，大约一分钟。过渡里不出东西，箭头也不出，天色慢慢变过去，音乐跟着换。
3. 过渡里纸鸟群照常来。第三幕那一回就放在过渡里。
4. 过渡不存档。过渡里退出的，下次打开直接是新一幕的第一件。

## 天色

故事要的是：第一幕黄昏，第二幕入夜到深夜，第三幕清晨到正午。

现在游戏里的天色是不动的，而且只认太阳高度。黄昏和清晨是同一套颜色，夜只有一档。所以要做这些：

1. 加一条按进度走的天色线。幕和幕之间的两段变天归过渡独占：过渡一从黄昏走到入夜，过渡二从深夜走到清晨。捡东西只在幕内推进：第一幕五件全程黄昏，一点不改；第二幕五件从入夜慢慢走到深夜；第三幕五件从清晨慢慢走到正午。进第二幕时是入夜，捡完第十件是深夜；进第三幕时是清晨，捡完第十五件是正午。2026-11-29 复审改定：原先写"第五件是入夜"，和"变天归过渡"打架。
2. 清晨要另配一套颜色，偏冷偏淡，和黄昏的橙紫分开。入夜、深夜、正午用现有的档。
3. 幕内每捡到一件，天色在十几秒里慢慢变过去，不跳。过渡里的变天走满整段过渡，不捡东西也变。
4. 中途退出再进来，天色直接是对应的那一档，不用慢慢变：进第几幕就从那一幕开头的天色算起，幕内已经捡到几件就再往下推几步。

## 存档

这几条是我补的，可以改。游戏现在没有任何存档，这是从零做。

1. 存两样东西：已经捡到几件，和这一局的编号。
2. 每捡到一件存一次。
3. 下次打开，直接从上次那一件接着追，不放引子。天色按「天色」第 4 条对到对应的那一档。
4. 存档坏了或者读不出来，当作从头开始，不报错。
5. 结尾放完进度清零。
6. 调试用的网址参数：`?frag=数字` 直接从那一件开始，`?frag=new` 清档从头来。
7. 换幕的过渡不存。过渡里退出的，下次打开直接是新一幕的第一件。

## 声音

这几条是我补的，可以改。游戏里的声音都是现场合成的，没有录音，也没有人声。

1. 捡到：一声很轻的叮。
2. 纸鸟群靠近：纸片哗啦的声音，从哪边来就偏向哪边。
3. 碰到：一声闷响。
4. 卡片出来和收走：一声很轻的纸响。
5. 音乐：第一幕照常，第二幕压低一半，第三幕回到正常，结尾放完淡出去。
6. 引子和结尾没有人念，只有卡片上的字。

## 代码上从哪里接

这一节写给实现的人。

- 现在的游戏没有目标，没有存档，没有能捡的东西，没有会追人的东西，也没有"世界上的一个点在屏幕哪个位置"这种代码。这几样都是新写。
- 每帧的流程在 `src/main.ts` 的 `stepFrame`，飞行和屏幕界面在 `src/game.ts` 的 `update`。新东西做成单独的模块，挂到这两处。挂的时候包在 try/catch 里，模块坏了不能影响飞。
- 飞机的位置和朝向从 `game.pose()` 拿。朝向零度是朝着 −Z，单位是米。速度每秒 34 到 78 米，巡航 46。高度 6 到 240 米。
- 天色只能靠 `sun.setAzEl(方位, 高度)` 加 `syncSun()` 去推。这两个都在 `main.ts` 的 `boot()` 里面，外面拿不到，要开个口子。
- 有一道测试绊线：`src/time-of-day.test.ts` 规定 `stepFrame` 那段代码里不许出现 `tod` 这个词，`todSpeed` 整个文件只能出现两处。天色的推进不要写进 `stepFrame`，不然测试变红。
- 现在的字幕在 `src/subtitles.ts`，固定八条，一次一行，新的顶掉旧的，还有测试钉着条数。纪念卡上的字不要走它，另写。
- 镜头摇晃是现成的：`src/director.ts` 算出一个 `traumaHit`，`src/game.ts` 把它交给 `feel.addTrauma`。碰到纸鸟群的时候往这里加一下。
- 屏幕边缘的箭头要把东西的位置投到屏幕上。要按 9:16 的画框算，不是按整个窗口。
- 调节面板在 `src/hud.ts`，时间滑杆和天色预设按钮都在里面。一局进行中要把这两样藏起来，通关后恢复。`src/hud.test.ts` 用源码文本钉着这个文件的好几处写法，动它之前先看那个测试。
- 那道光是透明的东西，守 `src/render-layers.ts` 的规矩：不写死 `renderOrder`，透明的东西不写深度。
- 测试用 vitest，在 node 里跑，没有浏览器。纯算的部分拆出来单独测：下一件出在哪、箭头指哪、进度和天色怎么对应、存档怎么读。碰画面的部分照老办法，读源码文本做检查。
- 分支用 `new-reset`。提交用英文的 Conventional Commits。不要自己提交或推送。

留给实现的人自己定的：五样东西的模型怎么拼，清晨的颜色具体是多少，箭头和卡片长什么样，纸鸟群和那道光用什么材质。

## 怎么算做完

1. 进度是零：起飞，引子三张卡，幕名卡一张，然后第一件在前方亮起，带着一道光。
2. 飞过去碰到它，画面暗一拍，卡片升上来，字是那一件的，看得清。
3. 卡片停够读完就收回，点一下也能收。下一件在别处亮起。
4. 把它飞出屏幕，屏幕边缘出现箭头和米数，照着飞得回去。
5. 飞离它超过一千五百米，它消失，在前方重新出现。
6. 纸鸟群按时出现，追过来，躲得开。被碰到时那一件被卷远，镜头晃，画面暗一拍。
7. 每幕五件。捡完第五件，过渡里天色慢慢走到下一幕的开头。三幕走完是从黄昏到正午。
8. 第十五件捡完出结尾，之后进度清零。
9. 中途关掉再打开，从上一次那一件接着来，天色对得上。
10. 新模块出错的时候，游戏还能照常飞。
11. 从头玩一局，计时在七到十分钟之间。
12. 一局进行中，点开调节面板，看不到时间滑杆和天色预设。通关以后点开，看得到。
13. `npm test` 和 `npm run build` 都过。
