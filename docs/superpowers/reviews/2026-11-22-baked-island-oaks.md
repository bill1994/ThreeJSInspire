# 110 米航线上的预生成叶簇树

在正午从海上飞向草坡，用右下角的「预生成叶簇树」和「风偏阔叶树」从同一起点重飞。种子、树位、草坡和太阳一致。图中左列为风偏树、右列为叶簇树，上排是海上接近，下排是越岸。远处林带变厚，越岸时能看见树冠边缘的细小透空。[可操作预览](http://[::1]:5181/?land=archipelago&pass=aerial&grasslook=paint&treelook=baked&tod=12&todspeed=0) · [两处同帧对照](../../../artifacts/oak-flight-1795331554912/comparison.png)

## 树库和绘制成本

使用 Just a Simple Tree 的橡树生成规则、带种子的随机数和橡树叶簇蒙版离线制作三棵母树。本项目把枝梢叶团简化为内层冠体及少量裁切面片，烘焙顶点色和叶团法线，导出一份共享 GLB。岛块载入后依原有树位确定性地选取树型。近树按原型实例化，合计最多三个近景批次，沿用 96 棵上限。[生成器源版本](https://github.com/MikeFernandez-Pro/just-a-simple-tree/tree/8fd94b8edc7ef1b87c086694382a0808c059971c) · [MIT 许可](../../../public/assets/island-trees/LICENSE.txt)

| 原型 | 离线种子 | 近树三角形 | 远树三角形 |
| --- | ---: | ---: | ---: |
| 宽冠 | 983 | 340 | 2 |
| 偏冠 | 7301 | 242 | 2 |
| 矮双冠 | 1522 | 174 | 2 |

每棵远树使用一张朝向相机的面片。每个原型烘焙 8 个水平角度、2 档俯角，合并成 1024 × 768 的 RGBA 图集。三种远树共享每岛一个实例批次。顶光与冠底色差保存在图集中，运行时叠加昼夜色调和雾。近岸倒影沿用风偏树的 30 面简模。

在「渐变」模式下，飞机接近岛屿时，远树会随视角逐渐混合相邻两张水平视图。俯视角在 12° 至 48° 之间时同时混合上下两排，共采样四张。每张视图按叶簇覆盖率贡献颜色和轮廓。继续飞近后，远树与立体树之间有约 0.55 秒的双向过渡。「硬切」模式可在相同树位复现原先的两种切换。[同航线重飞渐变](http://[::1]:5181/?land=archipelago&pass=aerial&grasslook=paint&treelook=baked&tod=12&todspeed=0&treelod=fade)

在 110 米航线上，可以盯住后方岛脊看远树首次出现。当前相机的远裁剪面为 2,000 米。树冠在距相机约 1,950 米处开始显现，到 1,440 米达到完整强度。远处叶簇采用连续透明度，飞机远离时沿同一距离带淡出。飞行中刚载入的岛块有 1.2 秒的淡入时间。起飞前已载入的岛块直接按距离显示。[远树渐显](http://[::1]:5198/?land=archipelago&pass=aerial&grasslook=paint&treelook=baked&treelod=fade&tod=12&todspeed=0&frameprobe=1) · [上一版同航线](http://[::1]:5197/?land=archipelago&pass=aerial&grasslook=paint&treelook=baked&treelod=fade&tod=12&todspeed=0&frameprobe=1)

生成器只参与制备。需要再烘焙时，在项目 Vite 服务可访问的临时目录放入上述版本的源码，在同源浏览器页面导入 `/scripts/bake-island-oaks.mjs`，用源码目录 URL 调用 `bakeIslandOaks`。结果中的 `glb` 为模型二进制，`views` 为 PNG 数据 URL，`records` 给出三种近树面数。输入叶簇蒙版已随树库保存。[离线配方](../../../scripts/bake-island-oaks.mjs) · [树库](../../../assets/island-trees/)

## 本机首分钟与越岸测量

以下数据采自加入渐变前的版本。使用独立 Chrome WebGPU 测试会话，高画质、450 × 800 绘制缓冲，正午直飞。两版各先采集固定步长截图，再在同一浏览器上下文中按 A/B、B/A、A/B 重新载入页面。实时采样从场景就绪后的动画帧开始，持续 60 秒，越岸窗口为飞机世界坐标 z 从 100 米到 −50 米。启动耗时包含本地开发服务的模块加载。表中列三次中位数，括号内为最小至最大。[各次原始统计](../../../artifacts/oak-flight-1795331554912/measurements.json)

| 指标 | 风偏树 A | 预生成叶簇树 B |
| --- | ---: | ---: |
| 首分钟超过 50 ms 的帧数 | 37（37–53） | 40（31–73） |
| 首分钟 p95 帧间隔 | 24.5 ms（17.4–25.4） | 24.5 ms（17.1–32.6） |
| 越岸 p95 帧间隔 | 17.4 ms（17.2–25.2） | 17.0 ms（16.9–25.0） |
| 导航至场景就绪 | 9.32 s（8.68–9.39） | 9.51 s（8.92–10.32） |

六次飞行均保持高档，近岸缺块计数均为零。越岸窗口的中位数接近，首分钟长帧的范围重叠且叶簇树的最差一次更高。此次结果支持将树形交给用户试飞，首分钟长帧验收仍待定位和复测。手机热机、持续三分钟跨岛及急转归入后续阶段。
