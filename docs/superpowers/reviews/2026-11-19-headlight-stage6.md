# 第六阶段：夜航前照灯

状态：实现与检查完成，等待用户画面反馈。第五阶段环境反射由用户确认。

## 实现

- 左翼下增加小灯壳和发亮灯面；灯位跟随 `porco_roll` 的世界变换，包含偏航、俯仰、侧倾及已有视觉摆动。
- 灯朝机身前方，下倾 6°；半角 14°，作用距离 170 m。空气光束、海面与 puff 受光共用位置、方向、强度和同一个柔边聚光函数。
- 空气光束采用有限空间内的 20 步积分，低画质为 12 步；沿程和边缘平滑衰减。积分读取场景深度，在飞机和海面前终止，背面代理盒不会直接着色为锥壳。
- 空气散射辐射上限为线性 0.05，灯面亮度也有限制。没有添加全屏白纱或新 bloom 通道。
- 海面按真实世界位置叠加柔和暖色受光，并保留波浪形体和远端雾。puff 的体积/旧 mesh 材质都接入同一光源；体积版本在可见密度的代表位置计算受光，不额外增加每个密度步的灯光采样。
- 默认 `auto`：太阳高度由 -6° 至 +1° 平滑熄灭，夜间亮灯；`on`/`off` 是手动覆盖。输入 `headlight=auto|on|off` 可复现，非法值回退自动。
- 正式右上角 UI 的时间轴下新增前照灯选项。读取的是当前太阳方向，时间轴切换后灯光状态同步更新。
- 第 1—5 阶段预览页固定 `headlight=off`。本阶段不改飞行物理、云散布或天空配色。

## 性能与边界

本机独立 Chrome，570×800 窗口 / 450×800 游戏区域；每组预热 30 帧，采样 120 帧。数字为推进一帧并等待 GPU 队列完成的墙钟时间，包含原场景渲染；同一编译着色器的开关对照仍保留海面/puff 的聚光计算节点。

| 模式 | P50 | P95 |
| --- | ---: | ---: |
| 高画质关闭 | 10.0 ms | 11.7 ms |
| 高画质开启 | 10.1 ms | 11.4 ms |
| 高画质再次关闭 | 10.1 ms | 11.5 ms |
| 低画质开启 | 8.5 ms | 9.1 ms |
| 低画质关闭 | 8.4 ms | 10.7 ms |

本轮开关差异接近测量噪声；不能据此保证所有移动设备都无开销。光束开启时新增一张代理盒的绘制与深度读取，灯壳/灯面各一张绘制，没有影子贴图或二次全场景照明渲染。

这是风格化局部照明：云上亮斑并非完整多次散射，尚未计算云沿灯光路径对另一朵云或海面的投影。空气光束与透明云依赖当前透明合成顺序，不能视作完整的相交体积积分。追尾机位下光束偏柔和光晕，侧面更容易看出方向；高空平飞时海面通常在主要照射范围之外，低空或俯冲时光斑更明确。
