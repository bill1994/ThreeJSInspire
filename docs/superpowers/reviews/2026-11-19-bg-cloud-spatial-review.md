# 背景云视差与远雾回收

背景云从整张固定天空立方图，改为有独立世界位置的远景云片。默认启用；`bgmotion=fixed` 可对照旧模式，单云标定夹具仍使用旧模式。

## 实现

- 共用原有 SDF、柔和亮部、调色板和噪声形状，每朵云单独烘成带透明度的图。烘焙射线、布局和噪声坐标不随飞机移动，所以不会重新引入飞行时云形漂移。
- 相机平移只改变各朵云的投影位置和角尺寸，产生随距离不同的视差；光照/时间变化仍按条带烘焙，完整快照完成后才发布所有云片。
- 使用 2.5D 朝向相机的远景云片，不提供穿云交互；近景穿云继续由 puff 承担。
- 远端 10–14 km 淡入天空，14 km 后完全不可见。回收的新云中心在 14.5–15.5 km；另有 3 秒出生淡入。近端 3.6–1.8 km 退出远景层，完全不可见后才回收。
- 世界窗口宽 32 km，越界时已经超出可见范围。长距离跳转同样将新云放在远雾之后；平时可见的云不移动、不重新散布。
- 绘制使用相机周围的 800 m 壳，位置和尺寸按真实世界距离投影，不改现有相机裁剪范围。相机 rig 更新后再更新云片，避免一帧滞后。
- 云雾只影响云自身，不增加全屏灰雾。未来统一场景雾可接 `BG_FIELD.fogStart/fogEnd`。
- 每片纹理最高 1024，保留每帧最多 8 条带的预算；冻结调时预览延长到 24 帧，足以处理在途和最新两轮快照。

## 验证

- `npm test -- --reporter=dot`：74 文件、814 测试通过。
- `npm run build`、`npm run smoke`、`git diff --check`：通过。
- `node scripts/bg-cloud-flight-probe.mjs`：真实 WebGPU 横移产生视差，可见云的世界位置不变；模拟直线飞行 60 km、26 次回收，全部在不可见处进行，新位置透明度为零；飞行触发的云纹理发布数为零。
- 清晨、中午、傍晚、夜间和多个朝向截图通过，无 WebGPU 报错。旧模式的接缝/亮部回归探针显式固定 `bgmotion=fixed`。
- 本机 448×797、bgq=512、含海面和体积 puff、90 帧 GPU 完成等待测量：固定模式 p50/p95 为 11.4/14.9 ms，空间云模式为 12.2/14.8 ms。此为本机对照，不代表所有设备的帧率。
