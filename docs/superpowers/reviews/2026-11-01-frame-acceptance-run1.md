## 3. 判定

- `sea_value_mean ≥ 0.45`（参考 0.488–0.637）：A 0.377 ✗、D 0.344 ✗；B 0.559 ✓、C 0.830 ✓。
- `sea_sat_mean ≤ 0.55`（参考 0.367–0.458）：**四态全超** 0.631 / 0.656 / 0.630 / 0.703 ✗。
  比改动前的 0.73–0.79 降了约 0.10，但离门还差 0.08–0.15。

`recompute_sea_bands.py` 的 CPU 门（`lit > 0.5` 面积 0.0954、`crest > 0` 0.013184）是在 shape 空间上过的，
帧上的饱和与亮度是另一回事——这两条门需要分开记，不能互相替代。

  文档原来的理由只是「`roadGate` 上限 1.0，结构上不可能产生峰」（`src/sun-road.ts:12-29`），现在帧上也确认了。

天穹的亮度梯度是反的：我们是地平线更亮、天顶更暗。K1 想修的「顶部 15% 带读不出深端层次」，
