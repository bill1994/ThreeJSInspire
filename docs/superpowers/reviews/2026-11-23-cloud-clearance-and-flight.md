# 群岛云型、云底净空与低空飞行复核

在阴影提交 `0c8b653` 上继续实施。固定群岛种子 20261120，默认手绘地面与体积近云，桌面 Chrome WebGPU，360 × 576 视口。[三种背景云实机截帧](../../../artifacts/cloud-clearance/final-flight/cloud-shapes.jpg) · [5.5 秒近云侧飞对照，左旧右新](../../../artifacts/cloud-clearance/cloud-flyby.mp4)

## 云层

- 生成、回收和传送按最终包围盒查询地表。取云体覆盖到的地形网格单元的最高顶点，给云底保留 7 米余量。放不下会换点，仍不满足条件就隐藏。穿云反馈分别使用宽、高、深；海上倒影沿用同一云体与淡出参数。
- 固定种子中，首朵宽近云的包围宽约 156 米，第七朵塔云高 143 米；两者低档都保留。塔云的最大体型为云底高度带预留了空间，散布按云朵各自尺寸检查环面间距。
- 背景云有横云堤、偏冠与双峰分体。首烘后一次测量图块的有效透明轮廓，优先安放大云。回收时先应用新图的宽高，再检查间距；侧飞造成视角变化时，次要云和同方位的地平线卡片按可见边距淡出。
- 在船屋岛绕行一周，再到 (299, −1880)、(−673, −7937) 两处山脊并折返。两档最低抽样云底净空 **13.42 米**，可见大背景云与其他世界云之间的最小测得角间隙 **5.62°**。这些数字限于本次路线。另有窄峰、跨地形格与方位角接缝的自动回归。

| 桌面观测 | 高档，前 → 后 | 低档，前 → 后 |
|---|---|---|
| 实际放置 / 本档启用 | 24 / 24 → 25 / 25 | 24 / 12 → 25 / 13 |
| 同时在视锥内且可见的近云中心峰值 | 5 → 5 | 4 → 3 |
| 距目标近云 210 米的大云机位，GPU 渲染 P95 | 0.701 → 0.812 ms | 0.327 → 0.274 ms |
| 环岛、回收和传送样本中，近云更新 CPU 峰值 | 0.9 → 0.6 ms | 0.9 → 5.4 ms |

GPU 样本按相同槽位、朝向与相对距离采集，每档各取 20 个预热后帧。CPU 峰值是单次路线中的最大值，低档有一次 5.4 ms 尖峰。侧飞短片每版 44 帧，按相对于各自目标云的同一条路径拍摄。[原始云场数据](../../../artifacts/cloud-clearance/final/report.json)

## 飞控、尾波与进港

- 70 米和 195 米起步，分别回放持续拉杆、松杆和主动推杆。70 米样本进入滞空后，持续拉杆约 0.60 秒转入低头，主动推杆约 0.10 秒。110 米起步时，浅俯冲最大俯角 23.4°，满杆约 68.7°；以 48 米为主动拉起触发点，两段最低高度分别为 47.3、44.2 米。新增轻微镜头反馈，仅在深俯冲后主动拉平时单次触发，沿用减震设置。[固定步长回放](../../../artifacts/cloud-clearance/controls.json)
- 黄昏贴海 S 弯，两档左右浮筒强度由约 0.39 / 0.98 变成 0.96 / 0.14；拉起到 26 米后均归零。保留现有双侧尾迹、岸边断浪和六帧水花。[低档换向截帧](../../../artifacts/cloud-clearance/final-flight/low-s-1.jpg) · [拉起截帧](../../../artifacts/cloud-clearance/final-flight/low-s-2.jpg)
- 固定时段飞向船屋，用前台动画回调驱动实际时间步。高、低档各采 540 帧，帧间隔 P95 均为 8.4 ms。高档有 3 帧超过 50 ms，峰值 208.2 ms；低档有 1 帧，峰值 358.3 ms。这项复核涵盖进港时的加载尖峰，具体耗时归属未作剖析。[飞行与实时帧间隔](../../../artifacts/cloud-clearance/final-flight/report.json)
