# 海面飞行时的断续横线

## 原因

海面由四层不同精度的方形网格构成。`holeInset` 原本只参与位移 mip 混合，网格索引仍按原始 `inner` 挖孔，导致前两道交界实际相切，没有注释所述的重叠区。不同网格的波浪位移和三角形插值会打开细缝，露出天空，形成断续浅色横线。第一圈还独有 C1 顶点位移，增加了交界处的不一致。

这与此前 15:53 天空黑色竖线的浮点数问题不同。

## 修复

- 网格挖孔实际使用 `inner - cell`，计数函数使用相同的格心裁剪规则。
- C1 的垂直和水平顶点位移在重叠区平滑减弱，片元波纹细节保持。
- 修正重叠测试：使用 `max(abs(x), abs(z))` 检查方形孔的真实边界。旧测试使用最小分量，外围跨坐标轴的顶点也会误判为存在重叠。
- 网格总三角形由 7496 增至 7736，增加 240；没有新增渲染通道或贴图。

## 验证

- 回归测试在修复前有两项失败，修复后通过。
- 全量 81 个测试文件、847 项测试通过；TypeScript 和 Vite 构建通过。
- `scripts/sea-seam-probe.mjs` 在真实 WebGPU 浏览器中固定 17:00、海拔 60、90 帧复现。禁用尾迹、风线和反射后仍有横线；临时用完整网格覆盖接缝则消失。
- 天空改成亮紫色且关闭反射的诊断截图中，海面区域 `(64,300)-(436,540)` 的亮紫漏色像素由 52 降至 0；修复后的正常画面横线消失，浏览器错误为空。
- 实际索引孔半径从 `[0,128,512,1500]` 改为 `[0,102.4,384,1300]`。
