# Puff 倒影柔化与双视域补云

用户反馈：puff 倒影清晰、浓重，像贴片，并且有突然出现的感觉。

原因：原平面反射只有 LOD 0.7 的轻度 mip 过滤，混合权重约 0.46–0.66；补云只判断天上云本体是否在屏幕外，没有检查镜像后的水面轮廓。

本轮调整：

- puff 捕获使用独立材质图，复用原密度纹理和光照 uniform。捕获 alpha 乘 0.38，并在捕获视距 1000–1750m 之间平滑衰减至零。主场景材质不变，避免再次让云心透出后层。飞机/未来地形不使用这个 puff alpha 系数。
- 物体反射 mip LOD 由原 0.7 改为随水面距离在 1.0–2.6 变化；近处飞机保留相对清晰的轮廓，远处倒影更柔。RGBA 同时过滤，保持预乘关系，无额外捕获 pass。
- 补云同时测试真实包围球与 y=0 镜像包围球。二者均完全位于屏幕边缘余量之外，才允许新 puff 准备。初始化建立好的云保留既有例外。
- 初始云心带由 950–1250m 移至 1250–1600m；净空由 850m 增到 1050m；窗口由 2800m 增到 3600m，距离淡出由 1000–1400m 调整至 1200–1800m。已有云仍可接近和穿入。
- 独立反射材质在云退出捕获集合或反射系统销毁时释放；不释放主场景材质、几何和共享纹理。

验证：

- 全量测试 842 项中，841 项首次通过；旧云对组合测试的 1000m 固定输入违反新的 1050m 净空，调整测试输入至 1300m 后相关 27 项全部通过。新增测试覆盖“本体在屏幕外而镜像在屏幕内”、反射材质独立所有权、同帧调参强制刷新和释放行为。
- 最终构建、smoke、diff whitespace 检查通过。
- 一分钟浏览器飞行回收：37 次新准备事件，本体/镜像可见区域内放行 0 次，无浏览器错误。记录 `artifacts/sea-puff-mirror-visibility-2026-11-20T06-51-42-553Z`。
- 固定近云同帧对照、白天高档/夜间低档/远云机位、连续转向与瞬移均无浏览器错误。近云倒影仍可辨认，远云贴片感显著降低。记录 `artifacts/puff-soft-sky-audit-ablation-2026-11-20T06-51-16-170Z`。
