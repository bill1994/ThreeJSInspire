# 夜间云倒影与云散布调整

用户要求：夜间云倒影更明显，但不整体提亮海面；bg-cloud / puff 避免成批跳出和新云轮廓扎堆。

## 实现

- 夜间环境反射仍使用已有 128px 云 cubemap，保持高档 4Hz / 低档 2Hz 的刷新预算，无新增捕获 pass。夜间降低波面法线对倒影的打散程度、略减模糊，并对云的预乘 RGB 增加有上限的局部贡献。天空空白 texel 不产生额外贡献，不改水体底色、曝光或月光带。
- bg 空间云和 puff 分别通过到达队列：每组至少间隔 0.9 秒放行一朵，透明度上升速度最多 0.25/秒（满透明度爬升需 4 秒）。保留原距离淡出；回收、瞬移后重新排队。
- 新云放行时检查水平视角轮廓间距和世界距离。puff 进一步要求相机到水平包围圆边缘至少 850m；错过远处放行机会的云保持隐藏，不会在近处补出来。已可见的云不会被重新排布，保留自然飞近、穿云及视差。
- 极远背景环保留四周覆盖，减小卡片角宽并移除方位抖动，减少邻接堆叠。空间云仍在原有远雾后回收。
- 完全透明的排队 puff 不参与穿云包围体，避免空气中触发白雾。

## 预览与回退

本机 `/night-cloud-lab.html` 默认午夜；同帧切换夜间倒影，云散布选择后重新加载。自由飞行链接可检查淡入与回收。对照页关闭前照灯以观察反射。

- `nightreflection=previous`：仅撤回本次夜间增强，保留前阶段的云反射。
- `scatterstage=previous`：原有云显示/散布行为。
- 新行为默认启用；无推送操作。

## 验证

- 全量 Vitest：79 文件 / 834 测试通过；最后收紧 puff 包围圆远端净空后重跑相关 43 项通过。生产构建、TypeScript、smoke 通过。
- 到达队列测试覆盖批量请求、淡入速度、角度接缝与同向遮挡、回收重置。
- 两分钟斜向飞行模拟覆盖多轮环面回收，确认新出现的云保持远端、透明度不跳升；另测近处排队云不放行、现有云可接近、瞬移重置和透明云不触发穿云。
- 浏览器同帧对照：`artifacts/sea-night-cloud-2026-11-20T03-43-24-661Z`。夜间飞行机位海面裁剪 RGB 平均绝对变化约 2.39/1.24/1.21（8-bit），22.2% 像素有任一通道变化超过 2；白天同帧差值为 0。
- 预览页：`artifacts/night-cloud-sky-audit-ablation-2026-11-20T03-44-48-272Z`。夜间高/低档、白天、同帧切换、连续转向及位置跳变无浏览器错误。无云负对照的海面裁剪逐像素一致（整页底部状态文字有异步更新，未算作海面）。

## 边界

倒影目前仍是天空与 bg-cloud 的环境反射，不含 puff、飞机，不是 SSR 或精确平面镜像。新云间距检查减少生成时重叠；飞机移动后自然发生的透视遮挡以及远景兜底层叠不强制消除，避免已可见的云突然消失。固定背景层不参与逐朵回收队列。
