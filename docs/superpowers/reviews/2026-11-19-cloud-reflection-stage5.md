# 第五阶段：天空与远云环境反射

状态：本轮实现与检查完成，等待画面反馈。第四阶段由用户确认。

## 实现与取舍

- 海面原来已有天空渐变的方向采样，本阶段加入实际空间 bg-cloud 与极远兜底云的颜色、形状及可见性。
- 独立场景复用云卡片的几何与材质，在相机附近生成 128² × 6 面的半浮点环境图；只绘制已有烘焙卡片，不重复执行体积云步进，也不捕获海面本身。
- 高画质每 0.25 秒、低画质每 0.5 秒更新一次完整立方体。转动视角只改变采样方向；云位移、回收与雾淡出在下一次捕获中同步。位置大跳转立即刷新，关云立即清除反射贡献。
- 环境图的 mip 1.5 柔化边缘；较平缓的波面法线将云影分成断续色块。按预乘透明度合成天空与云，避免透明边缘发黑。
- 保留原来的 Fresnel 权重与风格化水体结构，提高环境反射贡献，并把新版混合权重限制在 0.28 内。日月高光、浪花与远端地平线雾继续走原通路；反射没有额外夜间曝光乘法。
- `reflectionstage=previous` 恢复上一阶段的天空反射混合。当前主入口在 `sealook=painted` 时默认启用；前三阶段和第四阶段的 lab 固定到之前的反射状态。
- 本轮先交付这条环境反射路径，未实现局部平面反射或 SSR。当前主要对象为远天空和远云，先让用户判断这部分视觉收益；清晰的飞机/近处 puff 倒影需要另行引入局部反射方案。

## 性能记录与局限

本机独立 Chrome，570×800 浏览器窗口、游戏区域 450×800；每组预热 30 帧后统计 120 帧。测量为 `qa.step` 加 GPU 队列完成等待的墙钟耗时，不是纯 GPU 时间，也不是跨设备 FPS 承诺。

| 对照 | P50 | P95 | 捕获帧数 |
| --- | ---: | ---: | ---: |
| 高画质，关闭新版反射 | 10.1 ms | 11.6 ms | 0 |
| 高画质，开启 | 9.8 ms | 11.8 ms | 8 |
| 高画质，再次关闭 | 10.2 ms | 11.8 ms | 0 |
| 低画质，开启 | 8.1 ms | 10.1 ms | 4 |
| 低画质，关闭 | 7.4 ms | 9.1 ms | 0 |

高画质差异处于这轮测量波动内；低画质约增加 0.7 ms 中位耗时。测试是同一编译着色器的开关对照，旧版选项仍保留环境采样节点，因此不是独立旧构建与新构建的完整成本比较。测试在最后的权重上限与跳转刷新修订之前进行，这两项不改变常规捕获分辨率与频率。

环境图纹理的理论数据量约 1 MiB（含 mip，不含 GPU 对齐及驱动开销）。每次捕获新增六次小尺寸绘制；大部分帧复用结果。

该方案按远处环境处理云，相机附近的空间视差只在捕获时更新，不是每个海面点的精确反射射线。当前固定穹顶旧模式没有空间卡片时保留天空反射；近处 puff、飞机与尾迹不在环境图内。尚未进行移动设备或长时间飞行性能验收。
