## 手感和程序化验证

- 冻结同一张俯冲画面，分别渲染 0、2、4 像素的边缘模糊。三图中央 90×125 像素区域逐像素一致，左侧近景随强度增加而发生变化。实际飞行按俯冲强度连续调节。[关闭](../../../artifacts/flight-nov23/after/blur-0.png) · [2 像素](../../../artifacts/flight-nov23/after/blur-2.png) · [4 像素](../../../artifacts/flight-nov23/after/blur-4.png)

- 从 195 米起步触发顶棚恢复，在相同的约 0.57 秒内，原版从上仰约 58° 压至下俯约 47°，新版压至下俯约 4°。110 米起步满杆俯冲，进入 18 米高度附近时新版俯角约 17°，原版约 69°。实拍黄昏回放最低 7 米，掠水系数达到约 1，末段已拉起至约 73 米。[飞控和净空抽样](../../../artifacts/flight-nov23/flight-cloud-check.json) · [黄昏航迹](../../../artifacts/flight-nov23/after/dusk-trace.json)
- 近云一组 24 个，抽样宽度约 18–78 米。沿约 8.3 公里航线，对三个种子分别抽查 163,882 个云网格顶点位置与地形之间的高差。最小净空依次为 12.09、12.68、16.92 米。这个结果涵盖抽样航线，尚未穷举所有种子。
- 浏览器中将飞机移至约 15 公里外，确认起点岛被回收，再返回起点。地标的位置、高度和朝向完全复现，生成失败为零。远距离瞬移期间近区曾短暂缺 4 块，返回后为零；连续巡航及贴水采样期间近区缺块为零。[回收与重建记录](../../../artifacts/flight-nov23/after/return.json)
- 生产构建与 TypeScript 检查通过，85 个测试文件、878 项测试全部通过。三段左右对照录像各约 10.7 秒，以 7.5 fps 采样，浏览器中已验证可播放和跳转。录像采样率与游戏实时帧率分别记录。[全量测试结果](../../../artifacts/flight-nov23/final-tests.txt)

## 桌面性能与适用范围

桌面 Chromium WebGPU，360×600 视口，竖屏画布为 338×600，DPR 1。高低画质各取巡航和贴水约 22 秒。以浏览器相邻动画帧间隔计算 P95 和长帧；贴水段含近岸移位及资源加载。统计来自同机单轮对比，不能据此分摊每一个特效的 GPU 开销。[原版记录](../../../artifacts/flight-nov23/before/performance.json) · [新版记录](../../../artifacts/flight-nov23/after/performance.json)

| 航段 | P95 帧间隔，原版 → 新版 | 超过 50 ms 的帧数，原版 → 新版 | 最慢帧，原版 → 新版 |
| --- | --- | --- | --- |
| 高画质巡航 | 16.9 → 16.8 ms | 1 → 3 | 250.3 → 233.7 ms |
| 高画质贴水 | 16.8 → 16.9 ms | 7 → 6 | 533.8 → 283.6 ms |
| 低画质巡航 | 16.8 → 16.8 ms | 2 → 1 | 383.8 → 400.3 ms |
| 低画质贴水 | 16.8 → 16.8 ms | 2 → 0 | 66.8 → 33.4 ms |

对同一条连续掠水输入，在桌面 Node 单独比较 144 米覆盖范围的三档求解网格。64²、96²、128² 每次更新的 CPU 耗时 P95 分别约 0.15、0.18、0.29 ms。选择 96²，对应 1.5 米网格。这个微基准不含 GPU 纹理上传、整场景绘制及真实地形查询。[网格对比](../../../artifacts/flight-nov23/grid-cost.json)

画面评审中，岸线和远近层次在巡航时比尾波更容易比较，向外扩散的波纹在黄昏反光和连续贴水转弯时较清楚。与初版回放相比，最终又把转弯时呈完整圆环的泡沫收细，按角度断开，并让两边渐隐。此次可确认桌面渲染、程序化重建和自动输入结果；触屏长时间手感、目标手机热机帧时间、首见港湾的冷启动 GPU 耗时仍需真机测量。
