# 第一阶段：云覆盖与构图

## 本次改动

- 新增 16 张极远背景云卡片，复用现有中型云烘焙纹理，不增加体积采样或烘焙目标。方位固定在世界方向，随相机平移，表示极远背景；这一层不承担近景视差，也不需要回收生成。
- 原有空间云继续保持世界锚定、视差、雾后回收。大云尺寸系数 0.54，中云 0.86，减轻巨云顶满画面的情况。
- puff 只改散布：邻近云形成松散配对、拉近水平距离、协调云底高度。每朵的几何与缩放保持原值。位移必须同时通过远端净空、初始环带、环面最小间距检查，否则沿用原位置。
- `cloudlayout=legacy` 可恢复本阶段之前的背景云和 puff 布局；默认新布局。
- 本地预览页 `/cloud-composition-lab.html` 支持新旧布局、四个时刻、八个方位和自由飞行入口。与已有 lab 一样，不进入正式构建入口。

## 验证

- 74 个测试文件、816 项测试通过；新增 puff 配对的跨种子距离、出生净空、高度、确定性、输入不变检查。
- `npm run build`、`npm run smoke`、`git diff --check` 通过。构建仍有原先的混合导入/大包提示。
- 真实 WebGPU 截图：6、12、17.59、0 时，以及侧后方视角；无浏览器错误。
- 覆盖测试仅显示兜底云，以黑底排除天空、原空间云和 puff：横向每 10° 采样，俯仰 −15° / 0° / +15°，共 108 张截图。排除 UI 的画面区域每张均有明亮云像素，最少 25,741 个。
- 此覆盖结论针对测试中的正常竖屏飞行视场；不承诺直视天顶、垂直俯冲或任意缩窄 FOV 时仍然看见云。
- 60 km 连续飞行：26 次空间云回收均在不可见时发生，新位置位于雾后；世界锚定与视差检查通过，飞行引起的云纹理复制为 0。
- 本机固定画面的单次渲染加 GPU 等待计时，调整前后中位数均约 4.6 ms。仅为局部开销抽样，不等于完整飞行帧耗或其他设备性能保证。
- 预览页实测：新布局中午加载成功，切换旧布局清晨 / 315° 成功，自由飞行链接参数正确。
