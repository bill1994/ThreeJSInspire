# 第四阶段：尾迹、风絮及动态稳定性

状态：实现与检查完成，等待用户画面反馈。第三阶段已由用户确认。

## 实现

- 尾迹继续采样真实翼尖路径。使用出生时间与年龄驱动的连续低频扰动，旧段逐渐漂移、展宽、淡出；左右共享主要节奏，保留少量相位差，不使用逐帧随机抖动。
- 固定时间间隔采样，并在前后翼尖位置间插值。每段保存生成时的强度，转弯不会使已经消散的旧尾迹重新变亮。
- 横截面增加柔和透明边缘。夜间随环境转为较暗冷色，进入云体时减弱尾迹与风絮。
- 大距离位置跳转清空旧尾迹；接近垂直飞行时延续上一段侧向，降低带状几何翻面的风险。
- 风絮按真实相机朝向、视场角和宽高比计算屏幕边缘区域；淡入淡出并使用柔边点纹理，降低正中视野干扰。夜间及穿云时进一步收敛。
- 保持原粒子数量与固定尾迹缓冲；增加两张微型程序纹理，没有增加渲染通道。飞行物理未改动。
- 默认启用本阶段；`motionstage=previous` 恢复原尾迹和风絮。前三阶段预览页固定使用原动态效果，以维持历史对照。
