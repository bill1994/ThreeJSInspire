# 船屋航线 · 水陆机影与墙脚阴影

基线为 `aec9c76`。在基线上先录制进港，再用改后的工作区回放相同输入。[九秒并排录像，左旧右新](../../../artifacts/harbour-shadows/comparison.mp4) · [对照截帧](../../../artifacts/harbour-shadows/contact-sheet.jpg)

## 航线

群岛种子 20261120，岛屿 `0,-2`，船屋中心 X/Z 约 (721.27, −1222.18)。从 (720, 7, −1020) 朝 −Z 起飞，13 时固定太阳，360 × 576 桌面 WebGPU 视口，手绘地面、烘焙树。以 60 Hz 运行模拟，每六步取一帧。前后各 90 帧，采样时的飞机坐标逐帧一致。飞机约 4.1 秒越过水线，随后从距屋基中心水平约 3 米处掠过，再沿草坡拉起。[起点、输入与基线航迹](../../../artifacts/harbour-shadows/before/route.json) · [修改后航迹](../../../artifacts/harbour-shadows/after/route.json)

## 画面对照

- 约 1.3 秒看水面。新增的机影在白色浪纹与机身倒影之间。近海和地面共用当帧机位、航向、压翼程度与太阳方向，分别按海平面与实际坡高求投影。升高时边缘变软、阴影变淡。水体先接受阴影，再合成泡沫与倒影。
- 约 4.0 秒看屋基。墙脚的软暗边随船屋朝向贴在岸坡上，栈桥下方仍显示水面。验收岛地形网格约 27 米一格，房屋宽 11 米，因此在已有地形三角形上按实际屋基计算柔边。只有生成了船屋的岛块使用这一地面材质，日夜环境光沿用原地表。
- 两种效果均在现有绘制内完成。近海保留原有质量分档，机影独立于掠水波场。两段录像采集期间未记录浏览器运行错误。

## 同航线 GPU 成本

两个生产构建按同一套鼠标输入各走完整 540 步。桌面 Chrome WebGPU，360 × 576，预热后逐帧读取 render 时间戳。高、低档各跑三轮，轮换前后版顺序。表中每项为三轮中位数，最后一列按同轮前后版计算。

| 画质 | GPU P50，前 → 后 | GPU P95，前 → 后 | 绘制次数 P95，前 → 后 | 各轮 GPU P95 增量 |
|---|---|---|---|---|
| 高 | 0.943 → 0.952 ms | 1.166 → 1.185 ms | 222 → 222 | -0.004, +0.020, +0.038 ms |
| 低 | 0.612 → 0.623 ms | 0.739 → 0.749 ms | 154 → 154 | +0.012, +0.277, +0.008 ms |

三轮同档配对的增量均在计划的 0.5 ms 预算内。时间戳覆盖 GPU 渲染，加载和提交导致的前台实时长帧仍应单独测量。[逐帧原始数据](../../../artifacts/harbour-shadows/flight-performance/gpu.json)

低档另跑种子 20261120 和 991。两处屋基都随对应岛块卸载、随重访恢复，远近模型使用同一处阴影；关闭地标后地面无屋基阴影。对默认种子另取白天、黄昏、入夜截帧。[低档昼夜截帧](../../../artifacts/harbour-shadows/landmark-qa/daylight.jpg) · [岛块与模型检查](../../../artifacts/harbour-shadows/landmark-qa/checks.json)
