# 屏幕外补云、云心遮挡与物体反射

## 用户反馈与原因

上一版每 0.9 秒放行一朵，但淡入需要 4 秒，因此仍会同时看到多朵新云显形；它没有使用真实相机视锥。背景云把距离与兜底层强度乘进整张卡片的 alpha，实心区域也会透出后面的云。puff 的远端淡出同样削弱了整个云心的遮挡。

## 本轮实现

- 初始场景直接建立间距合格的云；后续新云仅在完整包围轮廓离开当前视锥（另加边缘余量）时准备好。准备好的云保持世界锚定，转向时自然进入镜头，不重新播放淡入动画。
- bg 世界位置可能超出相机 far，因此视锥判定故意忽略远裁面，避免把屏幕正前方的极远云误判成屏幕外。近裁面与四个侧面仍参加测试。
- 保留 360° 极远背景环；空间云继续在远雾后回收。puff 仍要求相机到水平包围圆边缘至少 850m；默认不再把初始散点二次压成紧邻云对。新云仍做间距检查，已可见的云不瞬移让位。
- 背景云的距离与弱化改为颜色趋近同方向天空，云心保持覆盖；只有软边及最外侧消隐带保留透明。已有远到近绘制顺序使近云遮住远云。puff 外部云心收实，保留软边和内部的光学积分，以维持穿云体验。
- 之前没有相机参数的离线调用仍有旧的渐入路径；生产主循环已传入实时相机，对照页复用最近的相机状态。

## 海面物体反射

新增独立低分辨率平面反射，仅捕获飞机、puff 与显式加入的地形。天空/bg-cloud 继续走原环境反射，不重复画进这张图。水面不进入捕获场景，避免递归。

- 高档：半分辨率，最长边上限 512，常规最高 30Hz。
- 低档：最长边上限 256，常规最高 15Hz。
- 明显转向/位置跳变强制刷新；相机进入水下、关闭反射或隐藏海面时停止相关捕获。
- 使用共享几何/材质的捕获副本，不更改主场景物体可见性。保留体积云需要的标准深度投影；水下裁剪交给独立 `ClippingGroup`。
- 反射使用捕获当帧的投影矩阵，配少量波浪扰动与柔化。空白 alpha 不改变海水，整体依旧走已有海霾收敛。
- 陆地尚未存在。本轮提供接入口：把地形根节点加入主 scene 后设置 `terrainRoot.userData.waterReflect = true`，其可见 Mesh 子节点会被收集。大型地形后续应结合反射专用 LOD 评估，未声称完成真实陆地的画面验收。
- 这是海平面上的近似倒影，不是逐个波面计算的物理反射。飞机倒影在贴海时更容易进入镜头，高空时可能落到画面下方。

## 验证

- 全量测试：80 文件 / 840 项通过；构建、smoke、diff whitespace 检查通过。
- `scripts/cloud-offscreen-probe.mjs`：一分钟斜向飞行与连续转向，41 次新准备事件，屏幕内放行 0 次。包含多轮 puff 回收；背景云也经过同一统计。浏览器错误 0。
- 红色背景遮挡测试：打开/关闭后方红面，前景云心 60×50 像素裁剪逐像素差值为 0；边缘仍柔和透光。记录 `artifacts/sea-cloud-flight-occlusion-2026-11-20T04-06-11-044Z`。
- `scripts/object-reflection-probe.mjs`：白天/夜间、正常飞行/背向光源、同帧开关。确认飞机及 puff 倒影出现。记录 `artifacts/sea-object-reflection-2026-11-20T04-02-36-308Z`。
- 新预览页高低画质、日夜、同帧开关、连续转向、瞬移无浏览器错误。记录 `artifacts/cloud-water-sky-audit-ablation-2026-11-20T04-05-03-027Z`。
- 单机顺序动态抽样，每档预热 30 帧后测 120 帧并等待 GPU 队列。高档关闭/开启均值约 10.04/10.47ms（增加约 0.43ms），p95 10.8/12.0ms；低档约 6.96/6.91ms，差值在波动内，不能解读为负成本。实际捕获尺寸 225×400 / 144×256，120 帧内各捕获 60 / 30 次。结果仅代表当前机器、画幅和场景，不是手机性能承诺。记录 `artifacts/sea-object-reflection-cost-2026-11-20T04-07-08-526Z`。

## 预览

本机 `/cloud-water-lab.html`。选择 60m 巡航检查云，选择 6m 贴海检查飞机倒影；点击自由飞行观察转向和回收。`objectreflection=off` 可关闭新物体反射，`scatterstage=previous` 为较早的云散布/透明背景对照。新行为默认启用，尚未推送 GitHub。
