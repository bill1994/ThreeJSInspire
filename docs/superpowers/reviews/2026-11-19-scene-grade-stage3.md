# 第三阶段：全天配色与飞机可读性

状态：实现与检查完成，等待用户画面反馈。第二阶段已由用户确认。

## 实现

- 新增 `applySceneGrade`，叠在原始太阳高度轨道之上、toon 与用户显式补丁之下。六个高度锚点线性空间平滑插值；天空、bg-cloud、puff、飞机灯光共用状态，海面的天空反射与远端颜色继续从同一状态派生。
- 清晨：朝阳侧保持暖色，背阳侧加强清蓝，减少原来的灰褐底色；云亮部为暖米色、暗部偏蓝灰。
- 中午：保留第二阶段的天空蓝；主光 2.6 → 1.9，半球光 0.85 → 0.65，并改善下方环境光颜色，使白色涂装保留亮暗层次。
- 黄昏：降低强紫/橙对比，用暖桃色、蓝紫灰组织天空与云；保留暖色气氛和原有海面高光。
- 夜间：月向主光 0.35 → 0.75，半球光 0.55 → 0.9，下方环境光改为较清楚的冷蓝。改善飞机机腹与浮筒，同时保留明暗面。未添加自发光、轮廓描边或新灯。
- 原夜空、星星、散射参数、全屏曝光与海面波形保持原控制方式。云只调整颜色，单朵造型、散布与柔和层次不变。
- `colorstage=previous` 返回第二阶段调色；默认启用第三阶段。`qa.setColorGrade(boolean)` 可在固定场景中切换；调色导出字符串携带此状态，显式颜色补丁仍具有最高优先级。
- 第一、二阶段 lab 固定到各自配色/海面版本，避免后续修改污染历史阶段对照。
