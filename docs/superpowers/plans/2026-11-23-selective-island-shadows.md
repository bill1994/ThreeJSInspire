# 群岛飞行的低开销阴影计划

**水陆机影与船屋墙脚阴影已实施并完成桌面验收。** [同航线画面对照与 GPU 数据](../reviews/2026-11-23-selective-island-shadows.md) · [进港实时帧间隔与长帧](../reviews/2026-11-23-cloud-clearance-and-flight.md)

首版解决两个画面问题。飞机从海面飞上湿沙、草坡时，玩家能从机影判断离地高度。低空飞过船屋时，能看清屋基落在岸坡上的位置。先用现有船屋验证，灯塔建成后复用这一做法。

## 1. 选定可重飞的验收航线

从默认种子 20261120 的群岛清单中选有船屋的海湾，记录岛屿 ID、起点、朝向、固定步长输入、太阳时刻、分辨率和画质。取约十秒的“贴海压翼 → 斜切湿沙 → 掠过船屋 → 越坡拉起”航段。先录现有版本，再用同一段航线单开机影、单开建筑阴影和同时开启。优先复用[低空交互计划](2026-11-23-low-flight-surface-interaction.md)中的航线和越岸机影任务；本计划把同一机影延伸到近海。

## 2. 让一枚机影连续落在水面和岸坡

- 按机型预生成一张软边俯视遮罩，保留从追尾视角容易辨认的主翼和机身。每帧在飞机姿态更新后取一次位置、朝向、侧倾和太阳方向。遮罩随航向转动，压翼时翼展投影适度收窄。[帧更新入口](../../../src/main.ts)
- 近海环和可见陆地用同一组参数，按接收表面的世界位置反推遮罩坐标。海上以海面为高度基准，岸上使用实际坡面高度，避免水线两侧的影子错位。太阳越低，影子向背光侧偏移越远；给偏移设上限，并在低太阳角、飞机拉高或离开近海环前平滑淡出。[海面材质](../../../src/sea/material.ts) · [群岛地表](../../../src/land/archipelago.ts)
- 只在投影范围内读取遮罩，把阴影作用于受日照的部分，保留水面倒影、白沫与地表笔触。海面机影独立于高画质尾波开关，低画质也能保留高度提示。首版预算为零新增阴影渲染通道、零逐帧纹理生成。
- 验收时看三个瞬间：贴水时辨得出机翼，斜过水线时同一枚影子能横跨水陆，爬升时轮廓逐渐变软、变淡。黄昏反向再飞一次，确认偏移服从太阳方位；入夜后太阳机影淡尽。

## 3. 先用船屋验证建筑接触阴影

岛屿生成时先确定船屋位置和朝向，再按建筑实际占地把墙脚附近的柔和暗色写入地形顶点色，栈桥伸入海中的部分单独裁掉。这个成本发生在生成岛块时。将效果与船屋的出现条件绑定，检查岛块卸载重访、船屋远近模型切换、关闭地标后的地表。若地形网格太粗、暗色沿三角形拉开，改用只覆盖屋基的贴坡小网格，并单独记录新增绘制次数。[岛块生成](../../../src/land/archipelago-data.ts) · [船屋尺寸与选址](../../../src/land/boathouse.ts)

灯塔建成后，用塔基半径定义接触阴影，在夜景镜头验收旋转灯束。若从正常飞行高度能明显看到塔身应当在坡面投下长影，再试一张只覆盖近处地标的太阳阴影图，从 512² 起测。限制参与投影的物件，在投影物、太阳方向或覆盖区域发生可见变化时刷新。塔身受太阳照射的长影与夜间旋转光束的遮挡分开评估。树林沿用已有林地底色，待首轮回放显示有具体问题时再评估。

## 4. 画面与性能验收

| 检查 | 方法与通过条件 |
| --- | --- |
| 视觉对照 | 正午、黄昏、入夜各录一次。对比贴水、过岸、掠屋三帧以及连续运动；关注水线跳变、草坡笔触盖住机影、倒影被重复压暗和岸边悬空的黑斑。另换一个有船屋的种子检查可复现性。 |
| 渲染成本 | 在同一设备固定分辨率和画质，等岛块加载、着色器预热后交替跑开关各三轮。参考群岛探针的 WebGPU 时间戳读取，比较各轮 GPU 渲染耗时 P50、P95 和绘制次数。首版暂定目标为组合开启后 GPU P95 增量不超过 **0.5 ms**，分别报告高低档。设备缺少时间戳时记录实际帧间隔，GPU 数值标为未测。[群岛性能探针](../../../scripts/archipelago-probe.mjs) |
| 飞行流畅度 | 用前台实时飞行复核帧间隔 P95 和超过 50 ms 的帧数，另记首次进港和岛块加载时的尖峰。若超预算，用单项对照定位；先缩小机影求值范围或简化软边采样，再复测同一航线。 |

实施交付为一段前后对照录像、同航线复现参数和实测性能表。近景实时长影作为后续独立实验，依据录像与剩余性能预算决定是否采用。
