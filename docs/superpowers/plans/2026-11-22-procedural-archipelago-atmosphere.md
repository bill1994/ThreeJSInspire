# 计划三 · 程序化群岛的光、空气与地标

**已实施，已完成桌面 WebGPU 验证，手机真机待测。** [执行记录与画面对照](../reviews/2026-11-23-flight-clouds-water-and-atmosphere.md)。 目标是在现有手绘群岛里，给平飞也带来值得留意的变化。主观察镜头是从海上接近两座岛之间的水道：近岸树冠和沙滩清楚，中景坡面有大片光影，远岬之间留出一段亮海。合适的湾口偶尔露出一个低矮屋顶，吸引玩家自己转向。这个镜头用于验收，场景由同一套规则沿航线持续生成。

## 从现有画面起步

以已有的 110 米竖屏越岸航线作美术基线。使用手绘草坡、预生成叶簇树及渐变切换、现有积云、海面与昼夜配色。保留草坡上成片的冷绿和黄绿、树冠的块面、淡沙色和红色飞机的辨识度。正午检查绿色和海岸轮廓，黄昏检查冷暖与反光，夜间检查暗部层次。参考[现有竖屏截帧](../../../artifacts/vivo-x90-island-flight.png)、[空中草坡评审](../reviews/2026-11-21-aerial-field-shading.md)和[叶簇树评审](../reviews/2026-11-22-baked-island-oaks.md)。

## 实施与画面判断

| 顺序 | 玩家应该看到什么 | 怎样接入当前程序 | 怎样判断是否值得保留 |
| --- | --- | --- | --- |
| 1 · 空气透视 | 从 110 米平飞，近岸能数出几簇树，中岛看得出向阳坡和背光坡，远岛是较淡但完整的轮廓。两岛间的水道仍然可辨。 | 从草坡已有的距离混色、树冠雾色及海面朝阳／背阳的地平线色入手。统一它们对同一距离、时段的响应，保留近景原色。先在现有材质中调节，无需新增全屏雾通道。 | 同一帧来回切换，观察远岛是否退入空气、近草是否发灰、树木远近切换时是否跳色。换到逆光和正午再看一次。 |
| 2 · 云影掠过海岸 | 平飞时先经过一块微凉的水面，再看见受光草坡；一条宽而柔的明暗边界可以同时跨过海滩和水面。 | 用世界坐标、种子偏移和模拟时间采样一个低频光照遮罩。先复用可平铺噪声，沿盛行风缓慢移动，调制陆地与海面的受光部分。飞机在自身位置取同一遮罩，树冠的近、远材质也共用它；海上倒影保留当时的受光关系。用大尺度云量和太阳高度控制幅度，夜间逐步减弱。 | 固定镜头等影子越岸，再让飞机穿过影缘。检查海陆接缝、转头后影子是否仍在原地、红机翼是否随环境轻微变光、落日亮带是否仍有层次。大范围明暗比小块噪点更重要。 |
| 3 · 同一阵风 | 从水面向岬角看，草坡的风纹与近水细碎亮纹大致同向；掠过之后，局部才留下飞机自己的尾波。 | 以现有海浪风向为参照，复用草坡风纹和水面已有的细节层。共享方向与一项缓慢变化的强度，草、水、云影各有自己的移动速度和响应幅度。保留草叶受到飞机扰动的局部运动，沿用既有 FFT 海浪谱。 | 固定镜头看一次自然风，再飞过同一位置。应能分辨环境运动和飞机造成的扰动。若逆光海面出现密集闪点，先减小细纹对比。 |
| 4 · 稀有海湾地标 | 多数岸段延续现在的沙滩和林地。偶尔先看到一小块褪色陶红的屋顶，靠近后认出坡脚的水上飞机棚和短木栈桥。另一些岬角只需一棵已有树型形成轮廓。 | 首版只制作一组可复用的低面数棚屋和栈桥。取现有草地阴影、沙色和木色作配色参照，屋顶压低饱和度，让红飞机仍是近景焦点。远处合并成简洁轮廓，近处才显示支柱。按下节规则选址与回收。 | 在普通巡航高度能发现屋顶，贴岸飞过才读到细节。换种子、反向接近、离开后返航，检查位置、朝向和稀疏程度；没有地标的岛靠光影也应成立。 |

主要接入点见[草坡与树冠着色](../../../src/land/field-shading.ts)、[昼夜调色](../../../src/scene-grade.ts)、[海面材质](../../../src/sea/material.ts)和[群岛加载与回收](../../../src/land/archipelago.ts)。

## 让规则延伸到后续岛屿

- 岛块生成时，通过世界种子和岛 ID 派生地标专用随机序列，沿岸取少量候选点。用岸线内凹程度、岸后坡度、朝水方向与盛行风给候选点排序。棚屋的角点要落在可用平地，栈桥从岸上伸向水中，同时检查树位和低飞通道。条件不足的岛自然留空。[岸形与实际地形高度](../../../src/land/archipelago-layout.ts)
- 用较大的区域限制地标密度。相邻区域候选过近时按稳定种子优先级选一个，加载顺序和接近方向都应得到同一结果。多格大岛按所属岛 ID 放置一次；地标描述随岛块生成和回收，共享模型与材质。开阔海域只计算当前可见的海面和光照。
- 在默认种子 `20261120` 之外，至少用两个固定种子回放相同规则。当前群岛入口固定了种子，实施时通过测试入口或 QA 参数注入对照种子。离开到起点岛被回收后返航，核对屋顶、栈桥与原有树位是否复现。相同种子与模拟时刻应复现云影，正常经过一段时间再返回时影子应随风前移。

## 三份计划一起执行与交付

1. **先留原版。** 固定种子、起点、输入、时刻、相机、画质与绘制分辨率，保存现有正午越岸及黄昏海峡片段。另选一段普通海岸作为对照，兼顾带地标和空岸的观感。
2. **先看十秒平飞。** [计划一](2026-11-22-flight-feel-clouds-and-water.md)的控制交接稳定后，在同一飞控版本上依次比较空气透视、云影、风纹、地标。每次只开一项，再看氛围全开。用固定模拟步长和相同影子相位，避免把不同光照时刻误判成改进。
3. **再看完整海峡航线。** 与[计划二](2026-11-22-flight-visual-effects.md)的俯冲、掠水 S 弯、拉起回看串起来。把云影、海面法线与泡沫接在各自的着色位置，重点看暗水中的尾波是否可读、近岸白沫是否抢过红飞机、岸上地标是否和倒影同时跳出。用同一飞控、云布局及水面版本单独比较计划三开／关，再比较原版与三份计划的组合版。
4. **交给用户看的结果。** 一段正午平飞左右对照、一段黄昏海峡完整动作左右对照，加一张不同种子的代表帧对照，标出相同规则生成的地标与普通海岸。保留可重飞的种子、起点、时刻与效果开关，让用户可以亲手验证。

## 性能取舍

土地与海面共享一次生成的低频纹理或等价解析信号，各材质按需采样。优先复用现有材质和时间更新，限制新增纹理采样与地标可见批次。低画质优先保留远近层次、大块光影和地标轮廓；若贴海时成本偏高，先简化水面阵风细节和栈桥近景细节。下列场景分别测量：

| 场景 | 需要记录的现象 |
| --- | --- |
| 开阔海面持续低飞 | 同分辨率、同画质下的 P95 帧时间及可用的 GPU 计时，区分海面每像素成本与个别长帧。 |
| 密集群岛、首次看到港湾 | 从冷启动到首次遇到地标的时间、超过 50 ms 的帧数、最慢帧、绘制调用和首次管线创建。对照现有[群岛长帧评审](../reviews/2026-11-22-island-flight-stutter.md)，检查新地标上传是否造成卡顿。 |
| 连续跨区、掉头返航 | 驻留岛数、地标实例数、几何及纹理内存趋势、加载队列与近岸缺块。实例随岛块回收，共享资源可在返航时复用。 |

桌面高档与低档分别采样，目标手机可用时补真机。数据里注明设备、画质和是否使用模拟视口。若某一步效果不明显或其成本超出同航线基线的正常波动，保留独立对照，让画面收益和具体代价都能被看见。
