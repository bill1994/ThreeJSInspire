# 群岛飞行体验优化计划

**首轮已实施并完成桌面 WebGPU 验证，手机真机待测。** 云型尺度、大云周边留白与高耸近云的地形净空仍有补充项，见下文。[首轮执行记录与画面对照](../reviews/2026-11-23-flight-clouds-water-and-atmosphere.md)

本计划基于 2026-11-22 对 `new-reset` 工作区的审核。首轮目标是让玩家在仰飞失速、俯冲拉平时能预期飞机的反应，并在贴海转弯后看见自己刚刚飞过的轨迹。

## 实施顺序与验收

| 批次 | 任务 | 实施要点 | 试玩时如何判断 |
| --- | --- | --- | --- |
| 1A | 仰飞与失速恢复 | 保留爬升耗能。先允许玩家主动推杆提前结束顶点停顿，再单独调节顶棚自动低头的角速度。分别回放两项改动，确认是哪项改善了手感。 | 分别从 70 米和 195 米满杆爬升，对比持续拉杆、提前松杆、失速时主动推杆。推杆能更早带下机头，越顶时仍能辨认地平线。 |
| 1B | 俯冲拉平 | 用离海高度和实际下降率估算触水时间，让高速俯冲更早进入渐进拉平。保留慢速贴海微调和岛上避障。 | 从 110 米浅俯冲、满杆俯冲，再各做一次主动拉起。观察最后半秒的机头角度、最低高度和镜头，检查辅助介入是否可预期。 |
| 1C | puff 云避让陆地 | 初次放置、跨区回收和大幅换位时，按整朵云的水平覆盖范围查询地形，给云底留余量。高度带不足时在屏外换点。同步更新云体、穿云反馈与反射所用位置。 | 用群岛种子 20261120，先复查世界坐标 X/Z 约为 (299, −1880)、(−673, −7937) 的样本，再做山脊侧飞、掉头和跨区回收。记录云底净空，观察山坡上的云边和倒影。 |
| 2A | 岸边碎浪 | 复用群岛岸线遮罩定位浪带，用世界坐标噪声打断覆盖，错开岸边各段的进退相位。现有遮罩约 10.4 米/格，先验证近岸特写是否需要补局部岸线几何。 | 高处能顺着浪带读出海湾形状，贴岸能看到碎浪分段推上沙滩。检查逆光、夜景和岛块切换时的亮边与接缝。 |
| 2B | 掠水双侧尾波 | 按航行距离记录水面落点、航向和生成时刻，用两条轻量波峰随时间向外展开、减弱，关联近水高度与速度。离水后让旧波纹继续消散，靠岸处裁掉落在陆地上的部分。 | 直飞贴水观察两翼方向，做一个 S 弯后拉起，确认旧航迹留在原来的水面，仍能读出两个弯。低画质单独验收。 |
| 3A | puff 云的大小与轮廓 | 将碎云、常规云、少量大云的尺度和宽高比拉开。同步评估按最大云计算散布间距的影响，核对实际可见数量、屏占比与体积云填充成本。 | 同种子、同航线录制连续片段。在同一镜头中能认出大小层次，穿过大云后仍能遇到零散小云；低画质也保有层次。 |
| 3B | bg cloud 形状池与大云留白 | 加入横向云堤、偏心高塔、中央断开的云群。复用烘焙图块与屏外回收，按权重抽选，并按可见轮廓的角宽给大云预留空间。 | 缓慢转向一圈再沿海峡往返。大云可以作为航向参照，前后相邻的云轮廓有差别，回收时画面里没有突然换形。 |
| 4A | 水花粒子与昼夜联动 | 先修正雾滴后移方向，把尾流、速度线和水花接到实时昼夜光照。再试一张 4–6 帧透明 PNG 图集，表现水舌升起、破碎、消散，从浮筒下方按贴水程度与倾斜方向发射。 | 分别做平飞掠水和压翼转弯，区分水纹与飞起的水滴。飞行中切换昼夜，检查水花亮度、透明边缘和重叠面积；低画质保留可辨认的双侧尾波。 |
| 4B | 俯冲速度感与舒适性 | 在 1B 手感稳定后，用空速与下降率调节屏幕边缘速度线的长度和强度，再比较轻微机身振动、拉起时的短镜头反馈。沿用现有减震设置。 | 同路线依次开关各效果。浅俯冲、深俯冲和拉起应有可辨区别；手机竖屏中心能持续看清飞机、海面与转弯方向。 |

## 云型尺度与散布的补充验收（1C、3A、3B）

这里的形态变化指不同云朵之间可辨认的宽度、高度、体量与轮廓。目标画面中，一片大背景云可以独占一段天空，近处既有小片碎云，也能偶遇从云底向上堆出数层的高云。

| 对象 | 当前默认试玩路径 | 待实施与验收 |
| --- | --- | --- |
| 大面积 bg cloud | 世界云已有大塔云、中型云、偏冠、横展及分体造型，首次布局会留角度间隔。高空云单独检查同层间距，地平线云带另行排布。[轮廓生成](../../../src/bg-cumulus-layout.ts) · [背景云各层](../../../src/bg-cloud-field.ts) | 从横铺云堤、宽底偏冠、双峰分体三种轮廓做出明确的大面积变体。用烘焙后的有效轮廓度量宽高，先排大云，再排其他背景云。世界云按边界预留正的净距，随大云尺寸增大；地平线卡片也要在对应方位、仰角留出天空。出生、屏外回收换图和换位都按最终尺寸重新检查。围绕验收岛转一圈并往返，记录大云旁最近云边的间距，检查留白有无被其他层填平。 |
| 大小、高矮不同的 puff cloud | 已有横铺、塔状、碎云和大体量四种配方。生成时会缩放；初排格距按云池中最大占地统一计算。体型和尺寸各自选取，选择塔形也可能抽到较小尺寸。[近云配方](../../../src/puff-shape.ts) · [逐朵缩放](../../../src/puff-cloud.ts) · [近云散布](../../../src/puff-field.ts) | 给宽大云和高耸云各留少量位置，让高云的云底仍处于同一片云层中，靠向上堆叠拉开高度。按实际宽、深及云型逐对留边距，周围的小云也遵守大云的留白；普通碎云仍能松散成群。高低画质都用侧飞和转弯画面检查相对尺度，并记录实际放置和可见数量。 |
| puff 与陆地 | 首次放置、回收、传送时已有 5×5 地形采样、抬升、换点与隐藏兜底。固定采样点可能跨过两个点之间的窄山脊。[地形避让](../../../src/far-field.ts) | 对每个候选位置按最终云体覆盖范围检查地形网格，取保守最高点，与最终云底比较并保留正净空。超过现有可用高度带就另选位置；放置成功后再开放穿云反馈和倒影。用首轮两个山脊样本加上云边擦过窄峰、跨岛回收、传送场景，记录最低净空。任何可见近云碰到陆地都算未通过。 |

先在固定种子样板中并排看三种大背景云及普通、高耸近云，再用默认飞行入口验收它们的实际出现比例。将净距、净空检查放在生成和回收阶段，复用现有烘焙和实例池。分别记录大云占屏最高时的 GPU 帧时间、回收时的 CPU 峰值，与同机位的首轮版本对照。

## 对比方法

- **飞控基线**。审核时以每秒 60 步固定输入回放。70 米起步满杆爬升约 2.6 秒后进入悬停；195 米起步触发顶棚恢复时，机头约 0.57 秒内从上仰 58° 转为下俯 47°；110 米起步满杆俯冲，约 0.32 秒内从下俯 64° 转为上仰 7°。实施时先在当时的工作区复跑，再对照输入、俯仰角、高度、速度和状态转换时刻。
- **海峡样板**。选现有群岛中的一段弯曲水道，固定种子、起点、航向、时段和镜头，依次沿岸下降、贴水转 S 弯、拉起回看。用入口岛坡、外侧碎浪与远处云形引导航向。海岸和尾波分别开关一次，再看组合画面。
- **性能与回归**。同路线比较改前改后的高低画质、帧时间 P95 和转弯时的长帧。重点观察大云占屏、近岸浪带和水花重叠三个片段。以目标手机实测评估成本，记录模拟设备结果时注明环境。飞控体验同时保留触屏试玩与固定输入回放。
